# 屏蔽门端门 —— 实现规格（已确认）

本文件记录端门方块的需求与实现约定，避免重复讨论。以下每一条都已与需求方确认。

## 1. 结构与形态

- 总高 **3 格**：
  - 下 2 格：玻璃门，**可动**；
  - 上 1 格：站台门玻璃的门楣（`psd_top`），**不动**。
- 形态定义：*"用站台门玻璃贴图的 MC 原版门 + 上方 PSD 玻璃门楣"*。
- 外观完全沿用普通 PSD 玻璃那一套模型与贴图；合并后在世界里与合并后的普通玻璃**没有视觉差别**。
- 后续可能为端门单独做一套模型（预留：模型名统一以 `psd_end_gate_` 开头）。

## 2. 方块状态

- 复用 PSD 玻璃的全部状态：`half=lower/upper`、`side=left/right/middle/single`、`facing`；
- 额外增加 `open=true/false`；
- blockstate 是与 `psd_glass_1.json` 同构的全量变体：facing 4 × half 2 × side 4 × open 2 = **64 组**。
  `open=false` 指向 MTR 原版玻璃模型（关着的外观与普通玻璃无差别），`open=true` 指向空模型
  `minecraft:block/air` —— 开着的门扇由方块实体渲染器整段画出来（见第 4 节），
  静态方块模型只能画自己那一格，跨格旋转做不到。
  （288 是 `psd_glass_end_1.json` 的口径：端头玻璃多了 `touching_left`/`touching_right` 各 3 个值，
  端门没有这两个属性，不适用。）

## 3. 合并

- 用**刷子右键**合并，与普通玻璃同一套合并逻辑；
- 合并后整段共享同一个 `open`（开门时整段玻璃一起动）。

## 4. 开门

- 方式：**整段旋转** —— 合并后的 N 格玻璃视为一扇大门，绕**最外侧**那根竖轴（门排到头那一端的格子边界、
  玻璃板中面）整体转 90°，摆向**站台侧**；
  注：站台侧 = `facing` 的**反方向** —— 屏蔽门的 `facing` 取的是玩家朝向，实装时人站在站台上朝轨道侧放，
  所以 `facing` 指轨道、站台在它背面；
- 实现：跨格旋转只能由方块实体渲染器 `RenderTrdmPSDEndGate` 画，且只由铰链那一格的下半格画一次；
  画的就是同一套 MTR 玻璃模型，所以开门后与关门时的贴图/边框完全一致；
- 碰撞：**只有全开（满档）才让出通道**；关着 / 半开 / 正在关都按玻璃板挡人，
  但**选中框要保留**（原版取物只看 `getShape`，做成空形状就点不到、门就关不回来）。
- **开度可调**（开合状态改成 `open=0..15` 共 16 档，每档 6°，整段共享）：
  - **短按右键** = 全开 / 全关；
  - **按住右键向下拖动** = 开度跟着鼠标走（向下开大、向上关小），**松手停在当前档位**；
    不需要潜行（潜行 + 刷子仍是外观设置）；
  - **开门有动画**：显示角度走 TrdmEndGateAnim 的客户端缓动（220°/s，90° 约 0.41 秒），
  所以单击开门是转着过去的、不是瞬间跳；
- **关门也有动画**：端门 blockstate 现在**全部是空模型**，门扇永远由渲染器画（用普通 PSD 玻璃的模型 + 那 2 像素位姿平移补偏移），所以开关两个方向都能缓动、不会和静态玻璃重影；
- 拖动时客户端按**连续角度**显示（TrdmEndGateDrag），方块状态仍是 16 档 ——
    平滑手感 + 现成的状态同步，不需要额外网络通道；松开时落到最近一档；
  - **拖动期间视角锁定**：`MouseHandlerTurnMixin` 在 `MouseHandler#turnPlayer` 开头把累积的鼠标位移
    取走（喂给拖动状态机）并取消原方法，所以镜头不转、位移只用来开门；
  - 拖动期间在**屏幕 UI 右侧居中**画一根竖直开度指示条（浅灰槽 + 青色填充、不带数字，`TrdmEndGateHud`，只在拖动时出现）；
  - 开合指令由客户端发 C2S（`psd_end_gate_open`，带档位），服务端只校验距离与方块类型后整段一起改。

## 5. 装饰条与灯

- 端门上**绘制带 slogan 的装饰条，但不绘制人字形（箭头）装饰**；
- 端门的门楣上**不画吊板 / 线路图 / 色带，只有一盏灯**（`RenderTrdmPSDTop` 见到下面是端门就直接返回）；
- 端门的门楣用**齐平的直角模型** `trdm:block/psd_end_gate_top`：面板厚 **2/16~6/16**（与端头玻璃的
  `psd_top_end_square_*` 一致，普通门楣是 0/16~6/16，会多探出 2 像素），且**不带** MTR 原版底部
  ±22.5° 的曲线倒角；由门楣方块状态 `end_gate`（下面是不是端门）选中；
- 装饰条**跟着门扇一起动**：由 `RenderTrdmPSDEndGate` 在门扇同一套 pose 里画，开门时贴着旋出去的门扇；
- 门楣上有灯：开门亮、关门灭；合并后，灯的位置按**整段 x 轴长度居中**；
- **端门的玻璃与门楣模型整体沿模型 x 轴 -2 像素**（`MODEL_X_OFFSET`）：几何照抄 MTR 的玻璃模型，
  只是平移 2 像素（普通玻璃 x 2~4 → 端门 x 0~2；门楣同理 x 0~4），用来和端头玻璃接上；
  渲染端所有「离方块中心的距离」（铰链轴、装饰条、门灯）都加上同一个偏移。
