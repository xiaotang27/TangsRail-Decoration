# 集控装置与通用设置

## 屏蔽门集控装置 `trdm:psd_control`

放在站台上，用来集中控制这一站台的屏蔽门。

| 操作 | 作用 |
|---|---|
| **刷子右键** | 打开设置界面：选站台（只列本站的站台）、开关「屏蔽门隔离」 |
| **空手右键** | 手动**保持开门**：门被持续压成开启状态，列车逻辑改不动它；再右键一次关回去，交还列车自动控制 |

- **屏蔽门隔离**：打开后这个站台的门**只受本装置控制**，列车到站不会自动开关门；
- 手动开门期间模组会每 tick 把门压回开启状态，所以列车逻辑和手动保持可以共存；
- 拆掉装置时，正在手动保持的门会自动交还列车自动控制。

## 通用设置

打开方式（两种都行）：

- **快捷键**：默认**没有绑定**，到「选项 → 控制 → 按键绑定」里自己设一个（分类 TangsRail Decoration）；
- **命令**：`/trdm config`。

设置项：

| 设置 | 存盘键（`config/trdm.json`） | 默认 | 说明 |
|---|---|---|---|
| 使用 TRDM 字体 | `use_trdm_font` | 开 | 用模组内置的思源黑体替换 MTR 原来用的字体，中文招牌更好看 |
| 启用乘客资讯屏幕广告视频播放 | `pis_video_enabled` | 开 | 关掉后 PIS 不再播放 mp4 广告（性能敏感时建议关） |

`config/trdm.json` 里同时还存着 **PIS 全局跑马灯**，可以手改。
改完回游戏按一次 `F3 + T` 重载资源，或在 PIS 屏幕设置里点「重新扫描」。
