# 方块交互操作
使用MTR模组的刷子物品右键点击TRDM的站名牌、PIS、屏蔽门集控装置等方块可打开该物品的设置界面进行设置。

蹲下（长按左Shift）并刷子右键点击TRD站台门方块，可以调整站台门信息吊板和玻璃门的外观设置。

## 站名牌

显示本站站名和月台所属线路下一站。

连续放置多个站名牌方块可使站名牌居中显示。

使用刷子右键方块可选择所要显示信息的站台。

## 站外站名牌
包含普通和悬挂两种款式。

可以连续放置多个方块以使信息居中显示。

使用刷子右键方块可打开设置界面选择显示的出入口名称和其他个性化设置。

## 站台门集控装置
不使用刷子右键可以让附近站台的站台门开/关一次。

使用刷子右键方块打开设置界面，可以调整要控制的站台和开启/关闭站台门隔离功能。

> 站台门隔离功能开启后，站台门开关只能使用集控装置控制，不受MTR自动运行的影响。

## PIS（乘客咨询显示屏）
自动检测附近站台的到站信息并在显示屏上显示。同时有信息显示跑马和广告播放区域。

使用刷子右键方块可打开设置菜单，以设置屏幕所显示的站台和跑马条、广告内容。您可以通过制作和添加资源包的方式在广告播放区域添加自定义的广告图片和视频。

> 使用PIS播放视频内容可能显著影响游戏性能，请谨慎使用。

### 跑马信息显示
可以设置全局内容和专属内容。

全局内容将会在游戏内所有屏幕上显示，专属内容只会在当前屏幕上显示。
