# 快速开始
TangsRail Decoration (TRDM) 塘铁装饰是一款基于 [Minecraft Transit Railway (MTR)](https://github.com/jonafanho/Minecraft-Transit-Railway) 模组的装饰和功能拓展性模组。目前仅支持Minecraft 1.20.1，使用Fabric模组加载器。

## 安装
将 MTR ， TRDM 的 jar 文件复制到 Minecraft 的 mods 文件夹即可。

- 如果使用 [YMTR](https://github.com/yomi-china/Yomis-Minecraft-Transit-Railway) ，还需要额外安装 Architectury API。

### 注意事项
TRDM 暂时不支持 MTR 4.x 版本。
