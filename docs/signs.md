# 站名牌

三种牌子，内容都来自 MTR：站名、线路色带、换乘线路标志、出口编号。

## 站名牌 `trdm:station_sign`

- 放置后用**刷子右键**打开界面选站台（只会列出本站的站台）；
- 显示**本站站名 + 下一站 + 线路色带**，颜色取该站台停靠线路的颜色；
- 终点站会自动显示「终点站 / Terminal Station」。

## 站外大站名牌 `trdm:big_station_sign_1`

深灰色横牌，用于站厅 / 出入口。放好后**用刷子右键**打开设置界面：

| 选项 | 说明 |
|---|---|
| 站名后缀 | `STATION` 或 `ZHAN`（把站名末尾的「站」写成 ZHAN） |
| 无障碍电梯牌 | 站名后追加「无障碍电梯」并在线路标签后加图标 |
| 出口 | 选择本牌的出口编号；出口列表来自 **MTR 仪表板里为这个车站定义的出口**，没定义过会提示 |

## 悬挂式站外站名牌 `trdm:hung_big_station_sign`

和大站名牌内容一致，但：

- 吊在天花板下方（单面有字，自发光），适合站台 / 站厅挂装；
- 设置项同上。

## 依赖的数据

站名、线路名、线路颜色、出口都从 MTR 的仪表板（Dashboard）读取，所以：

- 先建线路 → 建车站 → 建站台 → 在仪表板里给车站加出口；
- 换乘站会自动列出该站的多条线路标志。

## 外观替换

牌子的底图、标志、字体都可以用资源包替换，见
