## 放置规则

- 门扇一次放 **2 格宽**，玻璃 / 端头玻璃一次放 **1 格宽**；
- 都是 **2 格高**，并且自动在最上面第 3 格放一格门楣；
- 整排的铺开方向是**玩家朝向的顺时针方向**，方块的 `facing` 取的是**玩家朝向**
  （所以门是「站在站台上朝轨道看」的时候放下去的，这一点后面渲染要用）。

## 合并（刷子）

拿 **MTR 的刷子**右键门扇 / 玻璃 / 端头玻璃，会按 MTR 自己的拼接逻辑重算左右邻格的拼接状态
（`single` / `left` / `middle` / `right`），把它们焊成一整段：

- 玻璃段的拼接只影响贴图选型（哪边画边框、灯条）；
- **端门**的拼接还决定「整段算一扇门」，见下一节。

## 外观设置（蹲下 + 刷子）

**蹲下 + 刷子右键**门扇 / 玻璃 / 端头玻璃 / 门楣 / 端门 → 打开「屏蔽门外观设置」：

- **吊版风格**：门楣上那块板。可选：
  - **天津地铁站台门吊板**（默认，站名 + 左右线路标志）；
  - **津滨轻轨风格站台门吊板**（参考 Frame 88–91，滑动门上方是站名板，玻璃门楣只画线路图）；
  - **津滨轻轨风格站台门吊板（改造）**（参考 Frame 92–94，站名板英文保留 MTR 原文，换乘站左右各一个方形线路标志）。
- 两种津滨样式的动态贴图一直铺到门楣模型下沿、色带画在模型最底层；从 MTR 原版移植来的
  1.5/16 色带延伸只保留给天津地铁样式。
- **玻璃装饰线**：玻璃上那条带 slogan 的装饰带（天津样式 1 / 只有人字纹的样式 2）。

设置**作用到这一整段连续的门楣**，不是单格。

## 门楣与箭头

拿刷子右键门楣会翻转**整排**门楣的箭头方向（站点信息吊板、线路图吊板都读这个值）。

门楣内容（站名吊板 / 线路图 / 方向箭头 / 站台色带）由刷子菜单里的「吊版风格 + 是否常驻」决定，
数据来自 MTR 的站台和线路。

门楣的竖向接缝跟下方的门 / 玻璃分组走（MTR 原版行为）：一扇门（2 格）、一组用刷子合并的玻璃
内部用无缝门楣贴图；接缝只留在一组玻璃的两端、以及玻璃和滑动门之间。

## 端门（`trdm:psd_end_gate`）

- 结构：**下 2 格可旋开的玻璃门 + 上面 1 格门楣**（门楣随方块一起放出来）；
- **合并**：和普通玻璃一样拿刷子右键合并；合并后**整段共享同一个开合状态**，
  点任意一格，整段一起开 / 关；
- **开门方式**：整段玻璃被当成**一扇大门**，绕「最外侧那根竖轴」整体旋转，**摆向站台侧**；
  跨格旋转由方块实体渲染器完成，所以开门时外观和关门时完全一致（同一套 MTR 玻璃贴图）；
- **开度可调**：
  - **短按右键** = 全开 / 全关（和以前一样），**开门和关门都有旋转动画**（约 0.4 秒转完）；
  - **右键按住不放，鼠标向下拖** = 开度跟着鼠标走（向下开大、向上关小），**松手停在当前角度**；
  - **拖动期间玩家视角不动**（鼠标位移被截下来喂给门，不再转视角）；
  - 拖动时**屏幕右侧居中**会出现一根竖的开度指示条（浅灰槽 + 青色填充，不带数字），松手即消失；
  - 不需要潜行；潜行 + 刷子仍然是「屏蔽门外观设置」；
- **碰撞**：**只要开了就让出通道**（半开也能过人）；只有全关时才按玻璃板挡人
  （选中框还保留，所以开着也能右键点它关回来）；
- **门楣**：端门的门楣上**只有一盏灯**（开门亮、关门灭，合并后按整段长度居中），
  不画站名吊板 / 线路图 / 色带；门楣模型是「直角 + 与端头玻璃齐平」的专用模型；
- 端门的玻璃和门楣模型比普通玻璃**沿 -x 方向多挪了 2 像素**，用来和端头玻璃的玻璃面接上。

端门的需求与实现约定记在开发文档 `docs_fordev/end-gate-spec.md`。

## 盲道（`trdm:tactile_paving`）

- **贴地贴片**：只有一张贴地的平面（上下两面都画，物品栏里从哪面看都不空），无碰撞、不挡人；
  要放在完整方块的上表面（顶台阶也行），下面被拆掉时贴片跟着消失。平面比脚下方块顶面高
  0.25 模型单位（约 1/64 格），避免和 MTR 站台顶面贴花深度打架。
- **自动连接**：四个正方向各有一个 blockstate 布尔量 `north / east / south / west`，
  放置或邻格变化时只判断「紧贴着的邻格是不是盲道砖」，再交给 blockstate 选模型：
  - 一段连续盲道的**两端** → 点（`paving_2`）；
  - 直线的**中段** → 线（`paving_1`），南北向用原模型，东西向 `y=90`；
  - **转角 / 丁字 / 十字 / 单独一格** → 点（交点用点）。
- 贴图来自素材 `paving_1.png`（线）和 `paving_2.png`（点），复制为
  `assets/trdm/textures/block/paving_line.png` 与 `paving_dot.png`。

## 盲道台阶（`trdm:tactile_paving_step`）

- 半格高（8px）的盲道台阶：顶面复用 `paving_1`（线）/ `paving_2`（点），侧面和底面用
  `gray_paving`（1×1 纯色贴图）。
- 连接逻辑与贴地盲道完全一致：四个布尔量 `north / east / south / west`；端点 / 转角 /
  丁字 / 十字 / 单独一格 → 点，直线中段 → 线，东西向 `y=90`。
- 台阶只和台阶连接；贴地盲道和台阶各自成段。

## 高站台门延伸板（`trdm:psd_extension`）

- **用途**：放在高站台门门楣的同一高度（门上方第 3 格），把门楣继续往两侧或拐角延伸；
  和原版楼梯一样，`facing` 取玩家朝向，形状按四邻自动推。
- **三套现成模型**：
  - 直线段 → 普通高站台门「无倒角」门楣（`psd_top_left` + `psd_top_right` 拼成整格）；
  - 转角 → 直角转弯的 L 形门楣（`psd_top_end_square_left/right`）；
  - 拐弯后的那一段 → 端门门楣（`psd_end_gate_top`，4px 厚、和端门齐平），
    并会沿着这一段继续传播。
- **判定**：本格内侧（`facing` 的反方向）接了一块朝向另一条边的延伸板，且左右至少有一块
  同朝向的直线段 → 转角；左右紧贴着转角板、或已经判成端门门楣的同朝向延伸板 → 端门门楣段；
  其余 → 直线段。L 形回折边跟在转角内侧那块板的朝向上。
- 物品模型与直线段共用 `psd_extension_straight`（左右两半合并的整格门楣）。
