# PIS 乘客信息屏

PIS（Passenger Information System）是一块 **16:9 的吊挂横屏**，内容由 MTR 的实时到站数据驱动。

## 放置

- `trdm:pis` 直接贴墙 / 吊挂放置；
- 想架高就叠 `trdm:pis_pole`（显示屏柱），再把 PIS 放到柱子上。

## 显示内容

- 线路名与线路色、终点站、下一站；
- 到站倒计时 / 列车位置（读 MTR 的列车数据）；
- 站台跑马灯文字（本屏自定义 + 全局两段）。

## 屏幕设置（刷子右键）

拿**刷子右键** PIS 屏打开「PIS 屏幕设置」：

| 分区 | 内容 |
|---|---|
| 站台 | 这块屏跟着哪个站台的数据走 |
| 资源包设置 | 显示已加载的广告资源包数量、读到的广告条数，以及「重新扫描」按钮 |
| 广告显示设置 | 逐条广告的**启用开关**和**显示时长**（毫秒） |
| 跑马灯 | **本屏**文字（存在方块数据里，只在这一块屏上滚动）/ **全局**文字（存在 `config/trdm.json`，所有 PIS 先滚这段） |

## 广告

广告**完全由资源包提供**，模组本身不带广告内容：

- 清单：`assets/trdm/pis_ads.json`
- 素材：`assets/trdm/textures/block/pis/ads/`
- 支持 **png / gif / mp4**（mp4 实时解码，性能开销比图片大得多）

详细格式见 [PIS 广告资源包](resourcepack-pis-ads.md)。

## 视频开关

PIS 默认允许播放视频广告，但视频是实时解码的，掉帧明显时可以关掉：

- 游戏内：`/trdm config` 或快捷键打开「通用设置」→ 关闭「启用乘客资讯屏幕广告视频播放」；
- 或直接改 `config/trdm.json` 的 `pis_video_enabled`。

关掉之后 mp4 广告会被跳过，图片 / 动图不受影响。

## 贴图来源

PIS 的底图来自 JCM 的 TJPIS 资源包（开发时用 `importJcmAssets` 任务导入到
`assets/trdm/textures/block/pis/`），想换成自己的一套，用资源包覆盖同名贴图即可。
